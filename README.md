# ⌨️ Auto Arabic ↔ English Language Fixer (Keyboard Layout Converter)

Tired of typing a full sentence only to realize your keyboard was on the wrong language? 
This lightweight extension **automatically converts** text typed in the wrong keyboard layout between **Arabic and English**, saving you the hassle of retyping.

## 🚀 Key Features
* **Instantly Converts:** Seamlessly switches between Arabic ↔ English keyboard layouts.
* **Preserves Formatting:** Keeps spaces, punctuation, letter order, and original capitalization.
* **Universal Compatibility:** Works across all websites on standard inputs, textareas, and contentEditable fields.
* **Seamless & Non-Intrusive:** Works instantly via a simple shortcut without requiring a separate UI.

---

## 🎮 Simple Usage Guide

The fixer is activated via a shortcut:

1. Type your text normally (even if your keyboard language is wrong).
2. **Select** the text you wish to convert.
3. Press the shortcut: **Ctrl + Shift + Space**
4. Your text is instantly fixed! ✨
